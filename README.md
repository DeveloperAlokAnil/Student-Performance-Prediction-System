1. Project Title
Student Performance Prediction System Using Python
2. Overview of the Project
This project predicts a student's academic performance using basic Python. The system takes the student's name, daily study hours, attendance percentage, and previous examination marks as input. It calculates a performance score and classifies the student as Excellent, Good, Average, or Needs Improvement.
3. Features
• Enter student details.
• Enter daily study hours.
• Enter attendance percentage.
• Enter previous examination marks.
• Calculate predicted performance.
• Display the predicted performance percentage.
• Classify the student's performance level.
• Simple command-line interface.
• No external Python libraries are required.
4. Technologies/Tools Used
• Programming Language: Python
• Editor/IDE: Visual Studio Code
• Python concepts: Variables, input/output, arithmetic operations, if-elif-else statements, and basic data processing.
• External libraries: None.
5. Steps to Install & Run the Project
1. Install Python on the computer.
2. Install Visual Studio Code.
3. Create a Python file named student_performance.py.
4. Copy the project Python code into the file.
5. Save the file.
6. Open the VS Code terminal.
7. Run the following command:
   python student_performance.py
8. Enter the student information when prompted.
