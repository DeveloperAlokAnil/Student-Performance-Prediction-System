1. Problem Statement
Students' academic performance can be affected by factors such as study hours, attendance, and previous examination marks. It can be difficult to identify students who may need additional academic support at an early stage. This project provides a simple Python-based system that uses these inputs to calculate an estimated performance score and classify the student's performance level.
2. Scope of the Project
The project can be used to estimate student performance based on basic academic inputs. It can be extended in the future by adding more factors such as assignment marks, internal examination marks, participation, and previous semester results. The system can also be extended with a graphical user interface, database storage, charts, and machine-learning models.
3. Target Users
• Students – to understand their estimated academic performance.
• Teachers – to identify students who may require additional academic support.
• Academic coordinators – to monitor basic performance information.
• Educational institutions – as a starting point for student performance monitoring.
4. High-Level Features
• Student information input.
• Study hours input.
• Attendance percentage input.
• Previous examination marks input.
• Automatic performance score calculation.
• Performance classification as Excellent, Good, Average, or Needs Improvement.
• Simple command-line interface.
• No external Python libraries required.
